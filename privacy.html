Privacy Policy

Last updated: November 8, 2026

This policy describes how ViceDrop Uploader ("the app") handles information. The app is a personal tool used only by the owner of the ViceDrop YouTube channel.

What the app accesses

When the owner signs in with Google, the app requests permission to upload videos and manage video details (title, description, tags, schedule) on the owner's own YouTube channel through the YouTube Data API.

What we collect and store

The app does not collect personal information from any other users. The access token that Google issues after sign-in is stored only on the owner's own computer so that uploads can run without signing in each time. No data is sent to any server owned by us, and nothing is stored in a database.

Sharing

We do not sell, rent, share or transfer user data to anyone. Data is only exchanged between the app and Google/YouTube APIs in order to upload videos to the owner's channel.

Google API Services

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file also removes the app's access.
